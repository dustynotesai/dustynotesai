# 用 AI 排旅行

影片裡用的旅行 skill、ChatGPT 指令、空白模板和兩份範例都在這個資料夾。

**一句話：** 它會先問你、再去查、給你看過大綱，才排完整行程，最後做成一個可以在手機上看的行程頁和一份 PDF。
查得到的附上來源和查詢日期；查不到的老實標「未驗證」，最後給你一張出發前自己對的清單。

**Codex 和 Claude Code 用的是同一份 skill**（[`travel-planner/`](travel-planner/)），裝的位置不一樣而已。

## 它會怎麼跟你互動

**全程用中文，行程頁和 PDF 也是。** 你寫繁體它就回繁體，寫簡體就回簡體；想用英文，直接說「用英文回」。

1. **先問你幾題**：日期、幾個人、價格用哪個幣別看、預算、步調、哪些已經訂了。已經講過的不會重問。問完會讀一次給你確認。
2. **還沒訂的先幫你比**：城市之間的火車、飛機、巴士並排比，時間從飯店門口算到下一間飯店門口，錢也全部加起來；
   每個城市推薦住宿。**它只查、只比、只推薦，不會替你訂、不會付款。**
3. **先給你看每天的大綱**，你說好了才寫完整版。
4. **做好行程頁和 PDF**，加上一張「出發前自己對的清單」：每一班車、每一張要預約的票，連同日期和官方網站，一行一個 ☐。

**中間它停下來問你，是故意的。** 答完它才會繼續。不想被一題一題問，用 [`prompts.md`](prompts.md) 的「一次講完」。

**拿到的是第一版，不是定案。** 想改什麼直接說：「第三天太趕，刪一個點」「我自己找到飯店了，改住 ＿＿」，
它只改受影響的地方、重新做頁面，告訴你改了什麼。

**一趟一個資料夾**：行程存在 `trips/<城市>-<年-月>/`。旅行回來跟它說哪些去了，下次排同一個地方就不會再推一樣的。

## ⚠️ 出發前一定要自己確認

- **AI 會查錯，資料也會過時。** 我們抽查過它排的行程，大部分是對的，但也抓到票價寫錯、轉乘方向寫反，有幾格還標了「已查證」。
- **清單上的每一行，出發前都打開官方網站或 app 再對一次**，特別是標「未驗證」「待確認」的。
  同一個時間的火車，有的日子直達、有的日子要換車——要看的是**你出發那一天**的。
- **簽證、入境規定、護照效期**：以要去的國家官網、或你自己國家的外交部為準。
- **它不會替你訂任何東西。** 訂之前自己看清楚價格和取消規定。
