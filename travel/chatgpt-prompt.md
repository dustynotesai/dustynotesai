# ChatGPT 排旅行：複製貼上就能用

不用安裝任何東西。複製下面整段，貼進一個新的 ChatGPT 對話，把「＿＿」換成你的資料就好。
這就是[影片](https://www.youtube.com/watch?v=3i2-oc_Tu9s)置頂留言裡的那一段。

```text
幫我排一趟旅行。先看完下面的規則再開始。

我的資料：
・日期：＿＿ 到 ＿＿
・從哪裡出發：＿＿
・要去哪些地方：＿＿
・幾個人：＿＿
・價格用什麼幣別：＿＿
・已經訂好的：＿＿（機票、飯店、火車⋯⋯沒有就寫「都還沒訂」）
・想怎麼玩：＿＿（例如：一天兩三個景點、不想太趕）

規則：
1. 缺什麼資料，先問我，不要自己猜。
2. 城市之間怎麼移動，從我住的地方算到下一個住的地方，一段一段列出來。每一段寫時間、價錢、從哪個網站查的、哪一天查的。查不到的標「未驗證」。最後全部重新加一次。有好幾種走法（火車、飛機、巴士）的時候，每一種都這樣從頭算到尾，再比較。
3. 每一個班次都寫清楚是哪一天的班次；不是我出發那一天的，要直接講。
4. 最後給我一張「出發前我要自己對的清單」：把你在行程裡寫到的每一個班次時間、車次、轉車時間，連同是哪一天的，照原樣抄進清單；還有營業時間、要預約的東西。就算你覺得已經查到了，也要列進去，每一項附官方網站。
5. 不要幫我訂任何東西。
6. 回答最後用兩張表收尾，讓我一眼看完：
   ・比較表：每一種走法一行，寫出發時間、抵達時間、總共多久、轉幾次、總價；查不到的格子寫「未驗證」。
   ・清單表：就是第 4 條的清單，每一行開頭放一個 ☐，欄位是：日期｜時間｜車次｜哪一段｜官方網站。
```

**建議用有網路搜尋的對話。** 它反問你的話，照實回答；懶得答可以回「其他都用你覺得合理的就好」。

## 每一條規則在防什麼

| 規則 | 防的是 |
|---|---|
| 2「每一種都從頭算到尾，再比較」 | 只比「坐車多久、飛多久」，沒算到機場、報到、進城那一段——飛機看起來快，門到門其實沒省多少 |
| 3「寫清楚是哪一天的班次」 | 把別天、或一般時刻表上的班次，寫成你出發那天的，時間還寫得清清楚楚 |
| 4「就算你覺得已經查到了，也要列進去」 | 只把「沒查到的」標出來；查到但查錯的那一班，就沒有人會再對一次 |
| 1、5 | 自己猜你的日期；替你訂東西 |

## 我們實測的結果

同一段規則，拿同一趟（格林德瓦到佛羅倫斯的那一天）測過很多次，免費版和付費版都有：

- **兩張表每次都有給**，價錢和查不到的地方也大多老實標「未驗證」。
- **但它不一定真的查到你那一天的班次。** 多半是從一般時刻表或別的日期拼出來的，有時候自己會講，有時候沒講；清單也不一定把每一班都抄齊。

所以這段指令能做到的，是**讓它把要你自己確認的東西列出來**，不是保證它查對。
**出發前，清單上的每一行都打開官方網站或 app，用你出發那一天再查一次。**

想要 AI 真的去抓你出發那天的官方資料、把行程做成網頁和 PDF，用 [Codex](codex.md) 或 [Claude Code](claude-code.md) 加上這個資料夾的旅行 skill。
