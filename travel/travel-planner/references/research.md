# 查什麼、怎麼查、常見的藉口

SKILL.md 第 2、3 步的細節。每一個具體的數字和連結只有兩種狀態：**這次用工具查過**，或**標「未驗證」**。
第三方整理站查到的算查過，但要註明來源；官方站查得到的以官方為準。

## 逐項

| 項目 | 查什麼 | 寫法 |
|---|---|---|
| 機票 | 航班、直飛或轉機、總時間、行李額、每人價格 | 價格後面寫查詢時間；訂票網站查不到就給搜尋連結、價格標未驗證 |
| 城市之間 | 火車、飛機、巴士各自的門到門時間、價格、行李、轉乘、要不要訂位、開賣日 | 三種並排，推薦的標 ⭐ |
| 住宿 | 區域、每晚價格、到車站幾分鐘、免費取消期限 | 每城 2–3 家，一家 ⭐ 推薦加一句理由 |
| 火車／船 | 班次號、發車時間、月台、車門幾分鐘前關、訂位是否強制 | 查官方時刻表 |
| 售票 | 官方售票網址 | 不放 Google 搜尋結果、不放聚合站 |
| 定時票 | 他那一天還有哪些場次有位 | 「查詢時有位（YYYY-MM-DD）」或「查詢時已滿，改 XX:XX 場」；要登入查不到寫「名額未驗證」 |
| 景點 | 開放日、休館日、最後入場、整修中的入口變動 | |
| 餐廳 | 那天星期幾有沒有開、接不接訂位、夏休 | 每餐同區 2–3 家 |
| 當天城裡 | 國定假日、罷工、馬拉松、自行車賽、遊行、封路 | 公車地鐵停了寫替代方案（步行、共享單車、計程車） |
| 行李 | 車站寄物櫃在哪、大小、價格、人工或自助；飯店能不能先寄放 | 寫進退房日、移動日那幾格 |
| 出發前文件 | 依他的**護照國籍**查簽證或入境許可、要不要先線上登錄；護照效期規定；有租車就查國際駕照；保險 | 寫進「出發前要準備」，附官方連結；查不到寫未驗證 |
| 聯票、交通卡 | 聯票 vs 單買、交通卡 vs 單程票：照他的行程逐項加總比；一張票**能用幾天、含哪些、能不能隔天再進、要不要先開通** | 划算才推薦；買票那天放一格，之後用到的格子費用寫「已含 <票名>」 |
| 天氣 | 那個季節的天氣、那一天的預報（出發前 10 天內才查得到）；山上看不看得到 | 戶外為主、看天氣的那天，寫雨天備案 |
| 價格 | 當地幣、每人 | 換算標「約」加匯率日期；每人價、總額、付款授權、已扣款分開；聯票內的寫「已含」；算不清楚寫「待確認」 |
| 匯率 | 匯率、日期、來源 | 查不到就只寫當地幣 |
| 拍照 | 機位、光線時段 | 到構圖層級：不是「去 Trocadéro」，是「黃金時刻、藍調、亮燈三段拍」 |

頁面要點選才出得來（場次、票價）就用瀏覽器工具。

## 常見的藉口

| 你會想說 | 事實 |
|---|---|
| 「他說趕時間，我把假設寫出來就好」 | 假設寫出來還是假設。六題花他三十秒，錯一個進出城市他重排一整趟。 |
| 「他講中文，幣別應該是台幣」 | 講中文的人不一定用台幣——住在國外的、常出差的，用的都不一樣。問一句就知道。 |
| 「日期不知道也能先排個樣子」 | 沒有日期查不到班次、票價、開放日，整份都是未驗證。 |
| 「飛機比較快，建議搭飛機就好」 | 飛行時間短不等於門到門快。那一趟 chatbot 說格林德瓦到佛羅倫斯「全程火車太久（7–9 小時）」，推薦先搭火車到蘇黎世機場再飛——它只算了火車要坐多久，沒算飛機那邊要先到機場、提早報到、落地再進城。結果門到門差不多，機票每人卻是火車的三倍多。機票訂了才發現，已經退不掉。 |
| 「價格大概知道，寫個範圍就好」 | 機票和飯店價格每天在變。沒有查詢時間的價格，他拿去比就會比錯。 |
| 「幫他把最划算的直接訂下來」 | 不代訂。付款、取消規則、護照上的名字，都要他自己確認。 |
| 「骨架還沒定，先把每天排出來比較有進度」 | 城市晚數一改，每一天全部重排。骨架先定，或表頭寫清楚。 |
| 「這家餐廳很有名，不用查」 | 有名的餐廳最常週一休、八月放假。那一趟就砍掉一家週六日休息的。 |
| 「網址格式我知道，官網一定是這個」 | 那一趟有一個「官網」其實是介紹站，不能訂票。組出來的網址就是編的。 |
| 「先寫個大概的時間，他自己再查」 | 他不會再查。寫「未驗證」三個字，他才會。 |
| 「匯率大概 0.2，換一下就好」 | 大概的匯率就是編的數字。 |
| 「先把梵蒂岡排晚上，他訂的時候再看」 | 那一趟梵蒂岡夜場全滿，改 15:30 白場，同一天另外三格跟著作廢或挪時間。先查名額，一次排對。 |
| 「場次滿了，換一個時間就好」 | 換一格，那天前後就接不上。換了場次，整天重排。 |
| 「入境規定大家都知道」 | 規定跟著護照國籍和日期變。他沒問，不代表不用辦——那一趟使用者出發前幾週才問「IDP 是啥」。 |
| 「聯票一定比較划算」 | 要照他的行程加總才知道。那一趟的 24 小時票，使用者還得自己問「隔天能不能用同一張再進」。寫清楚能用幾天、含哪些。 |
| 「天氣到時候再看」 | 到時候他在山腳下。看天氣的那天，雨天備案先排好，他只要換一格。 |
| 「退房後直接去景點比較省時間」 | 拖著行李逛一整天。那一趟使用者一天一天改成先寄行李，最後要它從第 1 天到第 15 天全部檢查一次。 |
