# 問什麼，為什麼

每一題後面是它在那趟十五天裡對應到的東西。沒有對應的題目就不要問。

## 一定要問的六題（趕時間也問）

| 題 | 問法（給選項） | 為什麼 |
|---|---|---|
| 日期、出發地 | 「幾號到幾號？從哪裡出發？」 | 沒有日期查不到班次、開放日、那一天城裡有什麼活動 |
| 幾個人、跟誰 | 情侶／家人帶小孩／朋友／一個人 | Day 2 有「牽手走路」的拍照建議，一個人去就不會排；每人價和總額要分開算 |
| 幣別 | 「價格用哪個幣別看？台幣／美金／其他」 | **單獨問，不從語言猜。** 講中文的人不一定用台幣 |
| 預算 | 「不含機票住宿，每人每天大概多少？（用剛剛的幣別）」不確定就用「中」 | 每一格都有價（遊船、瑞吉山、梵蒂岡），要能說「這種我不要」 |
| 步調 | 滿檔／平均／放空不用腦 | Day 1 刻意輕鬆；移動日只留一件硬行程 |
| 已經訂好的 | 機票、住宿、城市之間的火車：都訂了／訂了一部分／都還沒訂 | 那一趟機票飯店火車是人先訂的，agent 只填中間。沒訂完的，先走 SKILL.md 第 2 步排骨架 |

## 骨架還沒訂才問的

| 題 | 問法 | 為什麼 |
|---|---|---|
| 想去哪裡 | 「想去哪幾個城市？還是只知道國家？」 | 只給國家就由你排城市和晚數 |
| 出發機場、轉機 | 「從哪個機場出發？可以接受轉機嗎？最多轉幾次？」 | 決定機票選項 |
| 艙等、行李 | 經濟／豪經／商務；要託運嗎、幾件 | 廉航的票價不含行李，比價會比錯 |
| 住宿偏好 | 區域（交通方便／安靜／有景）、類型（飯店／民宿／公寓）、每晚預算（他的幣別）、要不要能免費取消 | 住宿候選要能篩 |
| 城市之間 | 火車優先／可以飛／巴士也行 | 每一段還是會三種並排比，這一題只決定推薦哪個 |

## 3b · 排大綱之前一定要問的三題

六題決定查什麼，**這幾題決定每天排什麼**。第 4 步之前問完，一次一組。
他趕時間就用預設（平均走路量、09:00 出門、沒有硬指定），**表頭要註明**。

| 題 | 問法 | 為什麼 |
|---|---|---|
| 最想要的三樣 | 美食／歷史／海／山／拍照／購物／夜生活，選三個排序 | 決定每天的主線。那趟是拍照和美食，所以 Day 2 有一整條鐵塔機位 |
| 體力和走路量 | 一天走多少沒問題：5 km／10 km／不設限；爬樓梯 OK 嗎 | 穹頂 463 階加鐘樓 414 階一天近 900 階，砍掉了鐘樓 |
| 早起晚起 | 07:00 出門／09:00／10:00 以後 | 第一格的時間 |
| 一定要去、一定不去 | 各列三個 | 硬約束先擺進去 |

## 用到那一格再問的

大部分是第 5 步真的要寫那一格才問，一次問完。兩個例外：**護照國籍和租車跟第 2 步「骨架的題目」
一起問**（出國的行程，入境規定和國際駕照要靠這兩題查；骨架都訂好了就跟 3b 那一組一起問）——
兩個位置都在查資料之前，查得到。**不准塞進第 1 步的六題裡。**
⚠️ 以前這裡寫「第 1 步就問」，第一輪就變成 3 ＋ 5＝八題，而表頭寫的是六題。
另一個例外：**去過哪裡第 0 步先看 `trips/` 的舊行程**。

| 題 | 問法 | 為什麼 |
|---|---|---|
| 去過哪裡 | 先看 `trips/` 裡的舊行程（「已到訪」的格子）；沒有紀錄才問「這幾個城市去過的打勾」 | 去過就跳過經典景點 |
| 拍照到什麼程度 | 隨手拍／要機位／要構圖和光線時段 | 「黃金時刻、藍調、亮燈三段拍」是使用者要求的層級 |
| 飲食 | 不吃什麼、想吃什麼 | 餐廳那一格要能篩 |
| 護照國籍 | 「用哪一國的護照入境？」 | 簽證、入境許可、免簽天數都跟著護照走，要查才知道 |
| 會不會租車 | 不租／某幾天租／全程自駕 | 租車要國際駕照；那一趟 8/5 租車，使用者出發前才問「IDP 是啥」 |
| 行李 | 每人一個大行李箱／登機箱／只有背包 | 退房日、移動日要不要先寄行李、寄物櫃要多大。那一趟使用者一天一天要它改成「先放行李再逛」 |
| 交通偏好 | 火車優先／可以飛／要租車／可以騎共享單車 | 蘇黎世到佛羅倫斯，agent 說火車，機票已經訂了；巴黎沒公車那天，共享單車沒人提 |

## 問的方式

- **全程用他的語言。** 他用中文寫，每一組問題、讀回去、大綱、頁面上的字都是中文。
  第一組中文、第二組跳回英文是最常見的破綻——他中途不會換語言，你也不准換。
- 一次一組，**每組最多三題**（六題就是 3 ＋ 3），給選項。**第四題寧可等下一組。**
- 使用者答了「不知道」就給預設值，寫在表頭：「預設：中預算、平均步調」。
- 使用者說趕時間：只問前六題，其他用預設，表頭註明。
- **問完讀回去**：「我聽到的是：<M/D>–<M/D>，<幾個人>，<幣別>，每人每天約 <金額>，<步調>，
  <訂了哪些>。對嗎？」他說對才開始查。
