# 複製這幾句就能用

裝好 skill 之後，貼哪一句都可以。**不知道要貼什麼就貼第一句**，它會自己問你。

---

## 1 · 開始排（最短）

```
幫我排一趟去 ＿＿ 的旅行
```

它會先問你六題（日期和出發地、幾個人、幣別、預算、步調、訂好了沒），
讀一次回去給你確認，再去查。骨架還沒訂的話，會先比機票、城市之間的交通和住宿。
排大綱之前還會再問三題：最想要的三樣、一天走多少路和幾點出門、一定要去和一定不去。

**中間它停下來問你的時候，答完它才會繼續。** 那些停頓是故意的。

---

## 2 · 一次講完（不想被一題一題問）

把 ＿＿ 換成你的，整段貼進去：

```
幫我排一趟旅行，資料一次給你：

· 日期和出發地：＿＿ 到 ＿＿，從 ＿＿ 出發
· 幾個人：＿＿（一個人／情侶／家人帶小孩／朋友）
· 幣別：＿＿（價格要用哪個幣別看）
· 預算：不含機票住宿，每人每天約 ＿＿
· 步調：＿＿（滿檔／平均／放空不用腦）
· 已經訂好的：＿＿（都訂了／訂了一部分／都還沒訂）
· 護照國籍：＿＿
· 最想要的三樣：＿＿ ＞ ＿＿ ＞ ＿＿（美食／歷史／海／山／拍照／購物／夜生活）
· 一天走多少：＿＿（5 公里／10 公里／不設限），爬樓梯 ＿＿（可以／不行）
· 幾點出門：＿＿（07:00／09:00／10:00 以後）
· 一定要去：＿＿
· 一定不去：＿＿

排完做成行程頁和 PDF。
```

**幣別一定要寫。** 它不會從你講中文就猜你用台幣——住在國外的、常出差的都不一樣。

**預算不含機票住宿**，寫的是每人每天在當地花多少。

沒填的它還是會問。真的不想被問就加一句「**趕時間，其他用預設**」，
它會用預設值往下走，並且**把用了哪些預設寫在行程頁最上面**，你才知道哪幾件是它替你決定的。

---

## 3 · 拿到第一版之後（一定要改）

**交給你的是第一版，不是定案。** 自己讀一遍，哪裡不對就直接說：

```
第 3 天太趕了，拿掉一個景點
```

```
我自己找到飯店了，改住 ＿＿，那幾天的交通跟著改
```

```
＿＿ 我去過了，換一個
```

```
把第 5 天的午餐換成不用排隊的
```

它只會改受影響的部分、重新產生頁面，然後告訴你改了哪幾格。

---

## 4 · 旅行回來

```
我回來了，＿＿、＿＿ 有去，＿＿ 沒去
```

去過的會標成「已到訪」。**下次再排同一個城市，它就不會再推薦你已經去過的點。**
